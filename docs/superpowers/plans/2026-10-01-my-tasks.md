# My Tasks Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add an Asana-style "My tasks" page to the fork: every task assigned to the signed-in user or unassigned, across the workspace's active projects, as a list or board with search, filter, sort and group.

**Architecture:** One new read-only endpoint, `GET /api/my-tasks/{workspaceId}`, returns the tasks plus each project's columns. Everything else runs in the browser: pure functions in `apps/web/src/lib/my-tasks/` filter, sort and group the tasks; a route page renders them with list/board components; changes go through Kaneo's existing status/priority endpoints with optimistic cache updates; per-project websockets plus this tab's own mutations trigger refreshes.

**Tech Stack:** Hono + `@hono/zod-openapi`, Drizzle ORM (PostgreSQL), Vitest via `vp` (Vite+), React + TanStack Query/Router, dnd-kit, react-i18next, Base UI components in `apps/web/src/components/ui`.

## Plan rulings (decisions the spec left open)

1. **Archived and backlog tasks.** Kaneo has two virtual statuses outside the columns: `archived` (hidden from boards) and `planned` (the backlog). Archived tasks are excluded, as the due-date reminders already do. Backlog tasks are included; under Group by Status they form a **Backlog** group listed first. Dropping a card on Backlog sets status `planned`.
2. **Where preferences are stored.** They go in `localStorage` key `kaneo:my-tasks:<workspaceId>`, through a hook of their own. This is the same mechanism the project boards use for their filters (`kaneo:board-filters:<projectId>`). It avoids editing the shared `user-preferences` store, which keeps future upstream merges conflict-free.
3. **Priority sort.** "Ascending" means most urgent first (Urgent → No priority), which is what people expect from a priority sort.
4. **Due-date sort.** Undated tasks always come last, in both directions.
5. **Task panel in the URL.** The open task uses search params `taskId` and `taskProjectId`, because the panel needs the project and a task can leave the list while open.
6. **Sidebar entry.** It's one array entry in an upstream file. It's verified in the browser trial (Task 8) rather than by a unit test.
7. **Live updates.** The page opens one plain websocket per active project. There's no reconnect or keep-alive logic; refetch-on-window-focus covers dropped connections on a local install.

## Review Focus

1. **Same-tab edits.** Edits made in the task panel opened from My tasks happen in this tab, and the server never echoes websocket events back to the tab that made the change. The list must still refresh. Tested in Task 5 (`refreshes after any successful change made in this tab`).
2. **Time zones.** A due date saved as local midnight in a time zone east of UTC (the user is in Bangkok, UTC+7) must group as Today, never Overdue. Tested in Task 3: the due-bucket tests are also run under `TZ=Asia/Bangkok` and `TZ=America/Los_Angeles`.
3. **Missing columns.** Dropping a card on a status column that the task's project doesn't have must not move the task. It shows a message instead. Tested in Task 5 (`useMyTasksActions` → missing column).
4. **Completed tasks are never overdue**, in either the Overdue filter or the Due-date grouping. Tested in Tasks 3 and 4.
5. **Stale or corrupt saved preferences** (deleted project, unknown values, broken JSON) must fall back silently. Tested in Task 4 (`normalizePreferences`, `pruneFilters`) and Task 5 (preferences hook).

```ts
import { and, asc, eq, inArray, isNull, ne, or, type SQL, sql } from "drizzle-orm";
import db from "../../database";
import {
  activityTable,
  columnTable,
  labelTable,
  projectTable,
  taskRecurrenceTable,
  taskRelationTable,
  taskTable,
  userTable,
} from "../../database/schema";
import { taskIsCompleted } from "../../task/task-is-completed";

export const MY_TASKS_LIMIT = 2000;
export const COMPLETED_WINDOWS = ["hide", "7d", "30d", "all"] as const;
export type CompletedWindow = (typeof COMPLETED_WINDOWS)[number];

const WINDOW_DAYS: Record<"7d" | "30d", number> = { "7d": 7, "30d": 30 };
const DAY_MS = 86_400_000;

// When a completed task was completed: its latest status change, or its last
// edit when no status change was recorded (e.g. it was created in Done).
const completedAt = sql<Date | null>`case when ${taskIsCompleted} then coalesce((
  select max(${activityTable.createdAt}) from ${activityTable}
  where ${activityTable.taskId} = ${taskTable.id}
    and ${activityTable.type} = 'status_changed'
), ${taskTable.updatedAt}) end`.mapWith(taskTable.updatedAt);

function completedCondition(
  completed: CompletedWindow,
  now: Date,
): SQL | undefined {
  if (completed === "all") return undefined;
  if (completed === "hide") return sql`not ${taskIsCompleted}`;
  const since = new Date(now.getTime() - WINDOW_DAYS[completed] * DAY_MS);
  // Timestamps are stored as UTC wall time without a zone, like Drizzle writes them.
  return sql`(not ${taskIsCompleted} or ${completedAt} >= ${since.toISOString()}::timestamp)`;
}

const toIso = (value: Date | null) => (value ? value.toISOString() : null);

type GetMyTasksInput = {
  workspaceId: string;
  userId: string;
  completed: CompletedWindow;
  now?: Date;
  limit?: number;
};

async function getMyTasks({
  workspaceId,
  userId,
  completed,
  now = new Date(),
  limit = MY_TASKS_LIMIT,
}: GetMyTasksInput) {
  const projects = await db
    .select({
      id: projectTable.id,
      name: projectTable.name,
      slug: projectTable.slug,
      icon: projectTable.icon,
      position: projectTable.position,
    })
    .from(projectTable)
    .where(
      and(
        eq(projectTable.workspaceId, workspaceId),
        isNull(projectTable.archivedAt),
      ),
    )
    .orderBy(asc(projectTable.position), asc(projectTable.createdAt));

  if (projects.length === 0) {
    return { tasks: [], projects: [], truncated: false };
  }

  const projectIds = projects.map((project) => project.id);

  const columns = await db
    .select({
      id: columnTable.id,
      name: columnTable.name,
      slug: columnTable.slug,
      position: columnTable.position,
      isFinal: columnTable.isFinal,
      projectId: columnTable.projectId,
    })
    .from(columnTable)
    .where(inArray(columnTable.projectId, projectIds))
    .orderBy(asc(columnTable.position), asc(columnTable.createdAt));

  const rows = await db
    .select({
      id: taskTable.id,
      number: taskTable.number,
      title: taskTable.title,
      status: taskTable.status,
      priority: taskTable.priority,
      startDate: taskTable.startDate,
      dueDate: taskTable.dueDate,
      createdAt: taskTable.createdAt,
      projectId: taskTable.projectId,
      assigneeId: userTable.id,
      assigneeName: userTable.name,
      assigneeImage: userTable.image,
      completed: sql<boolean>`${taskIsCompleted}`.mapWith(Boolean),
      completedAt,
      isRecurring: sql<boolean>`exists (
        select 1 from ${taskRecurrenceTable}
        where ${taskRecurrenceTable.taskId} = ${taskTable.id}
      )`.mapWith(Boolean),
    })
    .from(taskTable)
    .leftJoin(userTable, eq(taskTable.userId, userTable.id))
    .where(
      and(
        inArray(taskTable.projectId, projectIds),
        or(eq(taskTable.userId, userId), isNull(taskTable.userId)),
        ne(taskTable.status, "archived"),
        completedCondition(completed, now),
      ),
    )
    .orderBy(
      sql`${taskTable.dueDate} asc nulls last`,
      asc(taskTable.createdAt),
      asc(taskTable.id),
    )
    .limit(limit + 1);

  const truncated = rows.length > limit;
  const taskRows = truncated ? rows.slice(0, limit) : rows;
  const taskIds = taskRows.map((row) => row.id);

  const labels =
    taskIds.length > 0
      ? await db
          .select({
            id: labelTable.id,
            name: labelTable.name,
            color: labelTable.color,
            taskId: labelTable.taskId,
          })
          .from(labelTable)
          .where(inArray(labelTable.taskId, taskIds))
          .orderBy(asc(labelTable.name))
      : [];

  const parents =
    taskIds.length > 0
      ? await db
          .select({
            childId: taskRelationTable.targetTaskId,
            id: taskTable.id,
            title: taskTable.title,
          })
          .from(taskRelationTable)
          .innerJoin(taskTable, eq(taskRelationTable.sourceTaskId, taskTable.id))
          .where(
            and(
              inArray(taskRelationTable.targetTaskId, taskIds),
              eq(taskRelationTable.relationType, "subtask"),
            ),
          )
      : [];

  const labelsByTask = new Map<
    string,
    Array<{ id: string; name: string; color: string }>
  >();
  for (const label of labels) {
    if (!label.taskId) continue;
    const list = labelsByTask.get(label.taskId) ?? [];
    list.push({ id: label.id, name: label.name, color: label.color });
    labelsByTask.set(label.taskId, list);
  }

  const parentByTask = new Map(
    parents.map((parent) => [
      parent.childId,
      { id: parent.id, title: parent.title },
    ]),
  );

  const columnsByProject = new Map<
    string,
    Array<{
      id: string;
      name: string;
      slug: string;
      position: number;
      isFinal: boolean;
    }>
  >();
  for (const { projectId, ...column } of columns) {
    const list = columnsByProject.get(projectId) ?? [];
    list.push(column);
    columnsByProject.set(projectId, list);
  }

  return {
    tasks: taskRows.map((row) => ({
      id: row.id,
      number: row.number,
      title: row.title,
      status: row.status,
      priority: row.priority,
      startDate: toIso(row.startDate),
      dueDate: toIso(row.dueDate),
      createdAt: row.createdAt.toISOString(),
      projectId: row.projectId,
      assignee: row.assigneeId
        ? {
            id: row.assigneeId,
            name: row.assigneeName ?? "",
            image: row.assigneeImage ?? null,
          }
        : null,
      labels: labelsByTask.get(row.id) ?? [],
      parent: parentByTask.get(row.id) ?? null,
      isRecurring: row.isRecurring,
      completed: row.completed,
      completedAt: toIso(row.completedAt),
    })),
    projects: projects.map((project) => ({
      ...project,
      columns: columnsByProject.get(project.id) ?? [],
    })),
    truncated,
  };
}

export default getMyTasks;
```

```ts
import { addWeeks, startOfDay, startOfWeek } from "date-fns";
import type { WeekStartDay } from "@/store/user-preferences";

export const DUE_BUCKETS = [
  "overdue",
  "today",
  "thisWeek",
  "nextWeek",
  "later",
  "noDate",
] as const;
export type DueBucket = (typeof DUE_BUCKETS)[number];

// Compares local calendar days: due dates are saved as local midnight, so a
// task due today must never read as overdue in time zones east of UTC.
export function dueBucket(
  dueDate: string | null,
  now: Date,
  weekStartsOn: WeekStartDay,
): DueBucket {
  if (!dueDate) return "noDate";
  const due = startOfDay(new Date(dueDate));
  const today = startOfDay(now);
  if (due < today) return "overdue";
  if (due.getTime() === today.getTime()) return "today";
  const nextWeekStart = addWeeks(startOfWeek(today, { weekStartsOn }), 1);
  if (due < nextWeekStart) return "thisWeek";
  if (due < addWeeks(nextWeekStart, 1)) return "nextWeek";
  return "later";
}
```

```ts
import type { WeekStartDay } from "@/store/user-preferences";
import { dueBucket } from "./due-bucket";
import type { MyTask, MyTasksFilters, MyTasksPreferences } from "./types";

export type FilterOptions = {
  userId: string;
  now: Date;
  weekStartsOn: WeekStartDay;
  search: string;
  showCompleted: boolean;
};

export type LabelOption = { key: string; name: string };

export const labelKey = (name: string) => name.trim().toLowerCase();

export function filterMyTasks(
  tasks: MyTask[],
  filters: MyTasksFilters,
  options: FilterOptions,
): MyTask[] {
  const query = options.search.trim().toLowerCase();

  return tasks.filter((task) => {
    if (!options.showCompleted && task.completed) return false;
    if (query && !task.title.toLowerCase().includes(query)) return false;

    if (filters.assignee.length > 0) {
      const mine =
        filters.assignee.includes("me") && task.assignee?.id === options.userId;
      const unassigned =
        filters.assignee.includes("unassigned") && task.assignee === null;
      if (!mine && !unassigned) return false;
    }

    if (
      filters.projects.length > 0 &&
      !filters.projects.includes(task.projectId)
    ) {
      return false;
    }

    if (
      filters.priorities.length > 0 &&
      !filters.priorities.includes(task.priority)
    ) {
      return false;
    }

    if (filters.due.length > 0) {
      const bucket = dueBucket(task.dueDate, options.now, options.weekStartsOn);
      const matches = filters.due.some((due) =>
        due === "overdue"
          ? bucket === "overdue" && !task.completed
          : due === bucket,
      );
      if (!matches) return false;
    }

    if (
      filters.labels.length > 0 &&
      !task.labels.some((label) => filters.labels.includes(labelKey(label.name)))
    ) {
      return false;
    }

    return true;
  });
}

export function labelOptionsFrom(tasks: MyTask[]): LabelOption[] {
  const options = new Map<string, LabelOption>();
  for (const task of tasks) {
    for (const label of task.labels) {
      const key = labelKey(label.name);
      if (!options.has(key)) options.set(key, { key, name: label.name.trim() });
    }
  }
  return [...options.values()].sort((a, b) => a.name.localeCompare(b.name));
}

export function countActiveFilters(prefs: MyTasksPreferences): number {
  const { filters } = prefs;
  return (
    filters.assignee.length +
    filters.projects.length +
    filters.priorities.length +
    filters.due.length +
    filters.labels.length +
    (prefs.completed === "hide" ? 0 : 1)
  );
}
```

`apps/web/src/lib/my-tasks/sort-my-tasks.ts`:
```ts
import type { MyTask, MyTaskProject, MyTasksSort } from "./types";

const PRIORITY_RANK: Record<string, number> = {
  urgent: 4,
  high: 3,
  medium: 2,
  low: 1,
};

const rank = (priority: string) => PRIORITY_RANK[priority] ?? 0;

export function sortMyTasks(
  tasks: MyTask[],
  sort: MyTasksSort,
  projects: MyTaskProject[],
): MyTask[] {
  const positions = new Map(projects.map((p) => [p.id, p.position]));
  const names = new Map(projects.map((p) => [p.id, p.name]));
  const position = (task: MyTask) =>
    positions.get(task.projectId) ?? Number.MAX_SAFE_INTEGER;
  const sign = sort.direction === "asc" ? 1 : -1;

  const primary = (a: MyTask, b: MyTask): number => {
    switch (sort.field) {
      case "dueDate":
        if (!a.dueDate || !b.dueDate) return 0;
        return sign * (Date.parse(a.dueDate) - Date.parse(b.dueDate));
      case "priority":
        // Ascending = most urgent first.
        return sign * (rank(b.priority) - rank(a.priority));
      case "project":
        return (
          sign *
          (position(a) - position(b) ||
            (names.get(a.projectId) ?? "").localeCompare(
              names.get(b.projectId) ?? "",
            ))
        );
      case "createdAt":
        return sign * (Date.parse(a.createdAt) - Date.parse(b.createdAt));
      case "title":
        return (
          sign *
          a.title.localeCompare(b.title, undefined, { sensitivity: "base" })
        );
    }
  };

  return [...tasks].sort((a, b) => {
    // Undated tasks stay at the bottom whichever way due dates are sorted.
    if (sort.field === "dueDate" && !a.dueDate !== !b.dueDate) {
      return a.dueDate ? -1 : 1;
    }
    return (
      primary(a, b) ||
      position(a) - position(b) ||
      (a.number ?? 0) - (b.number ?? 0) ||
      a.id.localeCompare(b.id)
    );
  });
}
```

```ts
import type { WeekStartDay } from "@/store/user-preferences";
import { DUE_BUCKETS, dueBucket } from "./due-bucket";
import {
  BACKLOG_STATUS,
  type GroupBy,
  type MyTask,
  type MyTaskProject,
  PRIORITIES,
} from "./types";

export type TaskGroup = { key: string; name: string | null; tasks: MyTask[] };

export type GroupOptions = {
  projects: MyTaskProject[];
  now: Date;
  weekStartsOn: WeekStartDay;
  showCompleted: boolean;
};

const byPosition = (a: { position: number }, b: { position: number }) =>
  a.position - b.position;

function fixedGroups(
  keys: readonly string[],
  tasks: MyTask[],
  keyOf: (task: MyTask) => string,
): TaskGroup[] {
  const groups = keys.map((key) => ({ key, name: null, tasks: [] as MyTask[] }));
  const byKey = new Map(groups.map((group) => [group.key, group]));
  for (const task of tasks) byKey.get(keyOf(task))?.tasks.push(task);
  return groups;
}

function groupByProject(tasks: MyTask[], projects: MyTaskProject[]) {
  const groups = [...projects]
    .sort(byPosition)
    .map((project) => ({
      key: project.id,
      name: project.name,
      tasks: [] as MyTask[],
    }));
  const byKey = new Map(groups.map((group) => [group.key, group]));
  for (const task of tasks) byKey.get(task.projectId)?.tasks.push(task);
  return groups.filter((group) => group.tasks.length > 0);
}

// Columns with the same slug in different projects share a group, named after
// the first project's column and ordered by the lowest position the slug has.
function groupByStatus(tasks: MyTask[], projects: MyTaskProject[]) {
  const info = new Map<string, { name: string | null; order: number }>([
    [BACKLOG_STATUS, { name: null, order: -1 }],
  ]);
  for (const project of [...projects].sort(byPosition)) {
    for (const column of [...project.columns].sort(byPosition)) {
      const known = info.get(column.slug);
      if (known) known.order = Math.min(known.order, column.position);
      else info.set(column.slug, { name: column.name, order: column.position });
    }
  }

  const groups = new Map<string, TaskGroup>();
  for (const task of tasks) {
    let group = groups.get(task.status);
    if (!group) {
      const known = info.get(task.status);
      group = { key: task.status, name: known ? known.name : task.status, tasks: [] };
      groups.set(task.status, group);
    }
    group.tasks.push(task);
  }

  const orderOf = (key: string) =>
    info.get(key)?.order ?? Number.MAX_SAFE_INTEGER;
  return [...groups.values()].sort(
    (a, b) =>
      orderOf(a.key) - orderOf(b.key) ||
      (a.name ?? "").localeCompare(b.name ?? ""),
  );
}

export function groupMyTasks(
  tasks: MyTask[],
  groupBy: GroupBy,
  options: GroupOptions,
): TaskGroup[] {
  switch (groupBy) {
    case "dueDate":
      return fixedGroups(
        options.showCompleted ? [...DUE_BUCKETS, "completed"] : DUE_BUCKETS,
        tasks,
        (task) =>
          task.completed
            ? "completed"
            : dueBucket(task.dueDate, options.now, options.weekStartsOn),
      );
    case "priority":
      return fixedGroups(PRIORITIES, tasks, (task) =>
        (PRIORITIES as readonly string[]).includes(task.priority)
          ? task.priority
          : "no-priority",
      );
    case "project":
      return groupByProject(tasks, options.projects);
    case "status":
      return groupByStatus(tasks, options.projects);
    case "none":
      return [{ key: "all", name: null, tasks }];
  }
}
```

```ts
  return sortedColumns(project).find((column) => column.isFinal)?.slug ?? null;
}

export function reopenTarget(project?: MyTaskProject): string | null {
  return sortedColumns(project).find((column) => !column.isFinal)?.slug ?? null;
}

export function toggleCompleteTarget(
  task: MyTask,
  project?: MyTaskProject,
): string | null {
  return task.completed ? reopenTarget(project) : completeTarget(project);

export type DropResult =
  | { kind: "none" }
  | { kind: "status"; status: string }
  | { kind: "priority"; priority: string }
  | { kind: "missingColumn" };

export const isDragEnabled = (groupBy: GroupBy) =>
  groupBy === "status" || groupBy === "priority";

export function resolveDrop(
  task: MyTask,
  groupBy: GroupBy,
  groupKey: string,
  project?: MyTaskProject,
): DropResult {
  if (groupBy === "priority") {
    return groupKey === task.priority
      ? { kind: "none" }
      : { kind: "priority", priority: groupKey };
  }
  if (groupBy === "status") {
    if (groupKey === task.status) return { kind: "none" };
    if (groupKey === BACKLOG_STATUS) {
      return { kind: "status", status: BACKLOG_STATUS };
    }
    return project?.columns.some((column) => column.slug === groupKey)
      ? { kind: "status", status: groupKey }
      : { kind: "missingColumn" };
  }
  return { kind: "none" };
}
```

```ts
  taskId: string;
  projectId: string;
  status?: string;
  priority?: string;

export function applyMyTaskChange(
  data: MyTasksData,
  change: MyTaskChange,
  now: Date,
): MyTasksData {
  const project = data.projects.find((p) => p.id === change.projectId);
  return {
    ...data,
    tasks: data.tasks.map((task) => {
      if (task.id !== change.taskId) return task;
      const next = { ...task };
      if (change.priority !== undefined) next.priority = change.priority;
      if (change.status !== undefined) {
        next.status = change.status;
        next.completed =
          project?.columns.some(
            (column) => column.slug === change.status && column.isFinal,
          ) ?? false;
        next.completedAt = next.completed
          ? (task.completedAt ?? now.toISOString())
          : null;
      }
      return next;
    }),
  };
```

```ts
function pick<T extends string>(
  value: unknown,
  allowed: readonly T[],
  fallback: T,
): T {
  return allowed.includes(value as T) ? (value as T) : fallback;
}

function list<T extends string>(value: unknown, allowed?: readonly T[]): T[] {
  if (!Array.isArray(value)) return [];
  const valid = value.filter(
    (item): item is T =>
      typeof item === "string" && (!allowed || allowed.includes(item as T)),
  );
  return [...new Set(valid)];
}

const asRecord = (value: unknown): Record<string, unknown> =>
  value && typeof value === "object" ? (value as Record<string, unknown>) : {};

export function normalizePreferences(raw: unknown): MyTasksPreferences {
  if (!raw || typeof raw !== "object") return DEFAULT_PREFERENCES;
  const saved = asRecord(raw);
  const sort = asRecord(saved.sort);
  const filters = asRecord(saved.filters);
  return {
    view: pick(saved.view, ["list", "board"] as const, "list"),
    groupBy: pick(saved.groupBy, GROUP_BYS, "dueDate"),
    sort: {
      field: pick(sort.field, SORT_FIELDS, "dueDate"),
      direction: pick(sort.direction, ["asc", "desc"] as const, "asc"),
    },
    filters: {
      assignee: list(filters.assignee, ASSIGNEE_FILTERS),
      projects: list(filters.projects),
      priorities: list(filters.priorities, PRIORITIES),
      due: list(filters.due, DUE_FILTERS),
      labels: list(filters.labels),
    },
    completed: pick(saved.completed, COMPLETED_WINDOWS, "hide"),
  };
}

// Saved filters can point at projects or labels deleted since; ignore those.
export function pruneFilters(
  filters: MyTasksFilters,
  projects: MyTaskProject[],
  tasks: MyTask[],
): MyTasksFilters {
  const projectIds = new Set(projects.map((project) => project.id));
  const labelKeys = new Set(
    tasks.flatMap((task) => task.labels.map((label) => labelKey(label.name))),
  );
  return {
    ...filters,
    projects: filters.projects.filter((id) => projectIds.has(id)),
    labels: filters.labels.filter((key) => labelKeys.has(key)),
  };
}
```

```ts
import type { TFunction } from "i18next";
import type { LabelOption } from "./filter-tasks";
import type {
  MyTaskProject,
  MyTasksFilters,
  MyTasksPreferences,
} from "./types";

export type FilterChip = {
  key: string;
  label: string;
  next: Partial<MyTasksPreferences>;
};

export function filterChips(
  prefs: MyTasksPreferences,
  projects: MyTaskProject[],
  labelOptions: LabelOption[],
  t: TFunction,
): FilterChip[] {
  const { filters } = prefs;
  const without = (
    field: keyof MyTasksFilters,
    value: string,
  ): Partial<MyTasksPreferences> => ({
    filters: {
      ...filters,
      [field]: (filters[field] as string[]).filter((item) => item !== value),
    } as MyTasksFilters,
  });
  const chips: FilterChip[] = [];

  for (const value of filters.assignee) {
    chips.push({
      key: `assignee:${value}`,
      label: t(`tasks:myTasks.assignee.${value}`),
      next: without("assignee", value),
    });
  }
  for (const id of filters.projects) {
    const project = projects.find((p) => p.id === id);
    if (!project) continue;
    chips.push({ key: `project:${id}`, label: project.name, next: without("projects", id) });
  }
  for (const value of filters.priorities) {
    chips.push({
      key: `priority:${value}`,
      label: t(`tasks:priority.${value}`),
      next: without("priorities", value),
    });
  }
  for (const value of filters.due) {
    chips.push({
      key: `due:${value}`,
      label: t(`tasks:myTasks.due.${value}`),
      next: without("due", value),
    });
  }
  for (const key of filters.labels) {
    chips.push({
      key: `label:${key}`,
      label: labelOptions.find((option) => option.key === key)?.name ?? key,
      next: without("labels", key),
    });
  }
  if (prefs.completed !== "hide") {
    chips.push({
      key: "completed",
      label: `${t("tasks:myTasks.filter.completed")}: ${t(`tasks:myTasks.completed.${prefs.completed}`)}`,
      next: { completed: "hide" },
    });
  }
  return chips;
}
```

```ts
import { useMutation, useQueryClient } from "@tanstack/react-query";
import updateMyTaskPriority from "@/fetchers/my-tasks/update-my-task-priority";
import updateTaskStatus from "@/fetchers/task/update-task-status";
import { myTasksKey } from "@/hooks/queries/my-tasks/use-my-tasks";
import { applyMyTaskChange, type MyTaskChange } from "@/lib/my-tasks/apply-change";
import type { MyTasksData } from "@/lib/my-tasks/types";

// Saves through the same endpoints as project boards, so activity, repeats and
// websocket broadcasts behave the same; the list updates before the server answers.
function useUpdateMyTask(workspaceId: string) {
  const queryClient = useQueryClient();
  const key = myTasksKey(workspaceId);

  return useMutation({
    mutationFn: async (change: MyTaskChange) => {
      if (change.status !== undefined) {
        await updateTaskStatus(change.taskId, { status: change.status });
      }
      if (change.priority !== undefined) {
        await updateMyTaskPriority(change.taskId, change.priority);
      }
    },
    onMutate: async (change) => {
      await queryClient.cancelQueries({ queryKey: key });
      const snapshots = queryClient.getQueriesData<MyTasksData>({
        queryKey: key,
      });
      queryClient.setQueriesData<MyTasksData>({ queryKey: key }, (data) =>
        data ? applyMyTaskChange(data, change, new Date()) : data,
      );
      return { snapshots };
    },
    onError: (_error, _change, context) => {
      for (const [queryKey, data] of context?.snapshots ?? []) {
        queryClient.setQueryData(queryKey, data);
      }
    },
    onSettled: (_data, _error, change) => {
      void queryClient.invalidateQueries({ queryKey: key });
      void queryClient.invalidateQueries({
        queryKey: ["tasks", change.projectId],
      });
      void queryClient.invalidateQueries({ queryKey: ["task", change.taskId] });
    },
  });
}

export default useUpdateMyTask;
```

```ts
import { useCallback, useEffect, useState } from "react";
import { normalizePreferences } from "@/lib/my-tasks/preferences";
import {
  DEFAULT_PREFERENCES,
  type MyTasksPreferences,
} from "@/lib/my-tasks/types";

const storageKey = (workspaceId: string) => `kaneo:my-tasks:${workspaceId}`;

function readPreferences(key: string): MyTasksPreferences {
  try {
    const stored = window.localStorage.getItem(key);
    return stored ? normalizePreferences(JSON.parse(stored)) : DEFAULT_PREFERENCES;
  } catch {
    return DEFAULT_PREFERENCES;
  }
}

export function useMyTasksPreferences(workspaceId: string) {
  const key = storageKey(workspaceId);
  const [prefs, setPrefs] = useState(() => readPreferences(key));
  const [loadedKey, setLoadedKey] = useState(key);

  // Another workspace: load its settings before rendering with them.
  if (loadedKey !== key) {
    setLoadedKey(key);
    setPrefs(readPreferences(key));
  }

  useEffect(() => {
    try {
      window.localStorage.setItem(key, JSON.stringify(prefs));
    } catch {
      // Storage may be unavailable or full; keep the settings in memory.
    }
  }, [key, prefs]);

  const update = useCallback((patch: Partial<MyTasksPreferences>) => {
    setPrefs((current) => ({ ...current, ...patch }));
  }, []);

  return [prefs, update] as const;
}
```

`apps/web/src/hooks/use-my-tasks-live-updates.ts`:
```ts
import { useQueryClient } from "@tanstack/react-query";
import { useEffect } from "react";
import { myTasksKey } from "@/hooks/queries/my-tasks/use-my-tasks";
import { getWsUrl } from "@/hooks/use-project-websocket";

const REFRESH_DELAY_MS = 300;

// Listens to every project's board socket. The server never echoes a change
// back to the tab that made it, so this tab's own successful saves (including
// edits in the task panel) trigger the refresh too.
export function useMyTasksLiveUpdates(
  workspaceId: string,
  projectIds: string[],
) {
  const queryClient = useQueryClient();
  const projectKey = projectIds.join(",");

  useEffect(() => {
    if (!workspaceId) return;

    let timer: ReturnType<typeof setTimeout> | null = null;
    const refresh = () => {
      if (timer) clearTimeout(timer);
      timer = setTimeout(() => {
        timer = null;
        void queryClient.invalidateQueries({ queryKey: myTasksKey(workspaceId) });
      }, REFRESH_DELAY_MS);
    };

    const sockets = projectKey
      ? projectKey.split(",").map((projectId) => {
          const socket = new WebSocket(getWsUrl(projectId));
          socket.onmessage = (event) => {
            try {
              const message = JSON.parse(String(event.data)) as {
                type?: unknown;
              };
              if (
                typeof message.type === "string" &&
                (message.type.startsWith("TASK") ||
                  message.type === "PROJECT_UPDATED")
              ) {
                refresh();
              }
            } catch {
              // Not a JSON frame; nothing to do.
            }
          };
          return socket;
        })
      : [];

    const unsubscribe = queryClient.getMutationCache().subscribe((event) => {
      if (event.type === "updated" && event.action.type === "success") {
        refresh();
      }
    });

    return () => {
      if (timer) clearTimeout(timer);
      unsubscribe();
      for (const socket of sockets) socket.close();
    };
  }, [queryClient, workspaceId, projectKey]);
}
```

```ts
import { useTranslation } from "react-i18next";
import useUpdateMyTask from "@/hooks/mutations/my-tasks/use-update-my-task";
import { resolveDrop, toggleCompleteTarget } from "@/lib/my-tasks/target-status";
import type { GroupBy, MyTask, MyTasksData } from "@/lib/my-tasks/types";
import { toast } from "@/lib/toast";

export function useMyTasksActions(
  workspaceId: string,
  data: MyTasksData | undefined,
  groupBy: GroupBy,
) {
  const { t } = useTranslation();
  const { mutate } = useUpdateMyTask(workspaceId);
  const projectOf = (task: MyTask) =>
    data?.projects.find((project) => project.id === task.projectId);
  const onError = () => {
    toast.error(t("tasks:myTasks.updateFailed"));
  };

  const toggleComplete = (task: MyTask) => {
    const status = toggleCompleteTarget(task, projectOf(task));
    if (!status) return;
    mutate({ taskId: task.id, projectId: task.projectId, status }, { onError });
  };

  const drop = (task: MyTask, groupKey: string, groupName: string) => {
    const project = projectOf(task);
    const result = resolveDrop(task, groupBy, groupKey, project);
    const target = { taskId: task.id, projectId: task.projectId };
    if (result.kind === "status") {
      mutate({ ...target, status: result.status }, { onError });
    } else if (result.kind === "priority") {
      mutate({ ...target, priority: result.priority }, { onError });
    } else if (result.kind === "missingColumn") {
      toast.error(
        t("tasks:myTasks.missingColumn", {
          project: project?.name ?? "",
          column: groupName,
        }),
      );
    }
  };

  return { toggleComplete, drop };
}
```

```tsx
  const dragEnabled = isDragEnabled(groupBy);
  // A short move turns a press into a drag; a click still opens the task.
  const sensors = useSensors(
    useSensor(PointerSensor, { activationConstraint: { distance: 6 } }),
  );
  const projectById = useMemo(
    () => new Map(projects.map((project) => [project.id, project])),

    const task = groups
      .flatMap((column) => column.tasks)
      .find((candidate) => candidate.id === event.active.id);
    if (task && group) onDrop(task, group);

            group={group}
```

```tsx
  const toggle = (field: keyof MyTasksFilters, value: string, checked: boolean) => {
    const current = filters[field] as string[];

      ? [...current, value]
      : current.filter((item) => item !== value);
    onChange({ filters: { ...filters, [field]: next } as MyTasksFilters });
  };

    field: keyof MyTasksFilters,
    options: Array<{ value: string; label: string }>,

        key={option.value}
        checked={(filters[field] as string[]).includes(option.value)}
        onCheckedChange={(checked) => toggle(field, option.value, checked)}
      >
        {option.label}
      </DropdownMenuCheckboxItem>
    ));

  return (
    <div className="flex flex-col gap-2 pb-3">
      <div className="flex flex-wrap items-center gap-1.5">
        <div className="relative w-full sm:w-64">

                  onChange({ completed: value as CompletedWindow })

              </DropdownMenuRadioGroup>
```

```tsx
export const Route = createFileRoute(

const NO_PROJECTS: MyTaskProject[] = [];
const SKELETON_ROWS = ["a", "b", "c", "d", "e", "f"];

function RouteComponent() {
  const { t } = useTranslation();
  const { workspaceId } = Route.useParams();
  const { taskId, taskProjectId } = Route.useSearch();
  const navigate = useNavigate();
  const { data: session } = authClient.useSession();
  const userId = session?.user?.id ?? "";
  const weekStartsOn = useUserPreferencesStore((state) => state.weekStartsOn);
  const now = useNow();
  const [prefs, updatePrefs] = useMyTasksPreferences(workspaceId);
  const [search, setSearch] = useState("");

  const { data, isLoading, isError } = useMyTasks(workspaceId, prefs.completed);
  const tasks = data?.tasks ?? NO_TASKS;
  const projects = data?.projects ?? NO_PROJECTS;
  useMyTasksLiveUpdates(
    workspaceId,
    projects.map((project) => project.id),
  );
  const actions = useMyTasksActions(workspaceId, data, prefs.groupBy);

  // Keep the panel's project while it animates closed.
  const [sheetProjectId, setSheetProjectId] = useState(taskProjectId);
  if (taskProjectId && taskProjectId !== sheetProjectId) {
    setSheetProjectId(taskProjectId);
  }

  const showCompleted = prefs.completed !== "hide";
  const filters = useMemo(
    () => pruneFilters(prefs.filters, projects, tasks),
    [prefs.filters, projects, tasks],
  );
  const labelOptions = useMemo(() => labelOptionsFrom(tasks), [tasks]);

  const visible = useMemo(
    () =>
      sortMyTasks(
        filterMyTasks(tasks, filters, {
          userId,
          now,
          weekStartsOn,
          search,
          showCompleted,
        }),
        prefs.sort,
        projects,
      ),
    [tasks, filters, userId, now, weekStartsOn, search, showCompleted, prefs.sort, projects],
  );

  const hiddenCount =
    filterMyTasks(tasks, DEFAULT_FILTERS, {
      userId,
      now,
      weekStartsOn,
      search: "",
      showCompleted,
    }).length - visible.length;

  const groups = useMemo(
    () =>
      groupMyTasks(visible, prefs.groupBy, {
        projects,
        now,
        weekStartsOn,
        showCompleted,
      }),
    [visible, prefs.groupBy, projects, now, weekStartsOn, showCompleted],
  );

  const openTask = (task: MyTask) =>
    navigate({
      to: ".",
      search: { taskId: task.id, taskProjectId: task.projectId },
    });
  const closeTask = () => navigate({ to: ".", search: {}, replace: true });
  const clearFilters = () => {
    setSearch("");
    updatePrefs({ filters: DEFAULT_FILTERS });
  };
  const handleDrop = (task: MyTask, group: TaskGroup) =>
    actions.drop(task, group.key, groupLabel(prefs.groupBy, group, t));

  const viewProps = {
    groups,
    groupBy: prefs.groupBy,
    projects,
    now,
    onOpen: openTask,
    onToggleComplete: actions.toggleComplete,
  };

  return (
    <>
      <PageTitle title={t("tasks:myTasks.title")} />
      <WorkspaceLayout
        title={t("tasks:myTasks.title")}
        headerActions={
          <ViewSwitch
            view={prefs.view}
            onChange={(view) => updatePrefs({ view })}
          />

          prefs={prefs}
          onChange={updatePrefs}
          search={search}
          onSearchChange={setSearch}
          projects={projects}
          labelOptions={labelOptions}
        />
        {data?.truncated && (
          <p className="pb-2 text-xs text-muted-foreground">
            {t("tasks:myTasks.truncated")}
          </p>
        )}
        {isLoading ? (
          <div className="flex flex-col gap-2">
            {SKELETON_ROWS.map((row) => (
              <Skeleton key={row} className="h-9 w-full" />
            ))}
          </div>
        ) : isError ? (
          <p className="py-8 text-center text-sm text-muted-foreground">
            {t("tasks:myTasks.loadFailed")}
          </p>
        ) : visible.length === 0 ? (
          <MyTasksEmpty hiddenCount={hiddenCount} onClearFilters={clearFilters} />
        ) : prefs.view === "board" ? (
          <MyTasksBoard {...viewProps} onDrop={handleDrop} />
        ) : (
          <MyTasksList {...viewProps} />
        )}
      </WorkspaceLayout>
      {sheetProjectId && (
        <TaskDetailsSheet
          taskId={taskId}
          projectId={sheetProjectId}
          workspaceId={workspaceId}
          onClose={closeTask}
        />
      )}
    </>
  );
}
```
